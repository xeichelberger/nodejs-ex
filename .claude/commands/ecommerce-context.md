# Ecommerce Context — Ashmi & Co.

**IMPORTANT:** Before executing any marketing, SEO, or CRO skill, read `brand/ashmi-brand-reference.md` for the full brand voice, customer persona, competitive landscape, and product context. All outputs must comply with the brand voice guidelines in that file.

## Quick Reference

- **Brand:** Ashmi & Co. — premium baby clothing (0-24 months)
- **Site:** shopashmi.co (Shopify)
- **Price Range:** $15 (accessories) to $80 (premium sets), AOV ~$60
- **Customer:** Millennial/Gen Z moms, 25-38, HHI $75K-$200K
- **Channels:** DTC (Shopify) + Nordstrom.com
- **Organic Traffic:** ~1,100 monthly sessions (major growth opportunity)
- **Email List:** 2,100+ active subscribers
- **Paid Ads:** Currently $0 (organic-first strategy)
- **Social:** Instagram ~41K, Facebook ~3.5K, TikTok (growing)
- **Key Differentiators:** Black-Owned, Women-Founded, Nordstrom partnership, occasion-ready design, quiet luxury positioning

## SaaS-to-Ecommerce Translation Guide

When applying marketing frameworks originally designed for SaaS, use these translations:

| SaaS Concept | Ecommerce Equivalent |
|-------------|---------------------|
| Signup flow | Checkout flow |
| Onboarding | Post-purchase experience (unboxing, first wear) |
| Churn / retention | Repeat purchase rate, customer lifetime value |
| Paywall / upgrade | Upsell, cross-sell, bundle offers |
| Free trial | Free shipping threshold, first-order discount, quiz/gift guide |
| Monthly subscription | Repeat seasonal purchases, new collection drops |
| Feature adoption | Product discovery across collections |
| NPS / health score | Review rate, repeat purchase rate, referral rate |
| Expansion revenue | AOV increase, cross-category purchases |
| MRR | Revenue per customer per year |
| Activation metric | First purchase → first review or repeat purchase |
| User engagement | Browse depth, wishlist usage, email engagement |
| Free tool | Free resource (style quiz, gift guide, size guide, lookbook) |
| Cold email | Influencer/press outreach |
| Competitor alternatives page | "X vs Ashmi" or "Best [category] brands" content |

## Content Voice Rules (Always Apply)

- Calm, intentional, warm, elevated, grounded
- Never use: "mama," "adorable," "cute," "obsessed," "game changer," "must-have," baby talk
- Do use: "these early days," "beautiful," "intentional," "quiet," "soft," "kept," "elevated"
- Write for the mom reading at midnight while nursing
- Sentimental without being saccharine
- SEO titles should be ones a real person would click on, not keyword salad
